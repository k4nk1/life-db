# 資産

## 取引タブ

**取引のフィールド**
| フィールド | 型 | 備考 |
|---|---|---|
| 取引日時 | datetime | 必須 |
| 金額 | int | 必須。プラス=収入、マイナス=支出、ゼロ=金銭移動なし |
| 詳細 | string | 任意 |

- 各取引の右端に削除ボタン

## 統計タブ

- 期間セレクタで月/週を指定（日は不要）
- 収入の取引一覧と支出の取引一覧を別テーブルで表示
- 上部に: 収入合計、支出合計、総損益（収入合計 + 支出合計）
  - 収入 = 金額がプラスの取引の合計
  - 支出 = 金額がマイナスの取引の合計
