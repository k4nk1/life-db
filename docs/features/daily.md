# デイリー

## 記録タブ

**日付選択**
- カレンダーで日付を指定。デフォルトは今日

**目標・振り返り**
- 各日付に対して目標（文字列）と振り返り（文字列）を1つずつ記録
- 未入力でも可

**タイムライン**
- 0時〜24時の縦軸目盛り
- 行動ブロックを時間帯上に配置
- 空白時間をクリック → 行動作成ダイアログ
  - タイプ: 大分類を選択 → その中の小分類を選択
  - 詳細: 任意の文字列
  - 開始時刻: タップ位置の時刻、終了時刻: 開始から30分後に自動設定
- 既存行動をクリック → タイプ・詳細を編集
- 行動ブロックの操作（実装時にライブラリ調査、なければ後回し）:
  - 中間ドラッグ → 移動
  - 上端/下端ドラッグ → 伸縮
  - 他の行動端・0時・24時にスナップ
  - 行動同士は重ならない

## 統計タブ

- 期間セレクタで期間を指定
- 大分類/小分類の切り替えが可能
- 表示内容:
  - 円グラフ（タイプ別の時間割合）
  - リスト: 各タイプの総時間、割合(%)、一日平均時間

## タイプタブ

- 大分類のCRUD。各大分類は名前と色を持つ
- 小分類のCRUD。各小分類は名前を持ち、1つの大分類に属する。色は持たず、グラフ等では大分類の色で表示
- 大分類を削除すると配下の小分類も削除される
