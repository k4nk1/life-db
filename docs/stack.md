# 技術スタック

## 言語
- **TypeScript** — フロントエンド・バックエンド共通で使用し、型定義を共有する

## バックエンド
- **Node.js** — TypeScriptとの親和性
- **Express** — シンプルで軽量、変更が容易
- **Prisma** — 型安全なORM、マイグレーション機能あり

## フロントエンド
- **React** — コンポーネントライブラリのエコシステムが最大
- **Vite** — 高速なビルド・HMR
- **MUI (Material UI)** — UIコンポーネントライブラリ（下記参照）
- **TanStack Table** — ヘッドレステーブルライブラリ（ソート、展開、ツリー構造、インライン編集）
- **React Router** — ページルーティング

## データベース
- **SQLite** — 個人利用に最適、ファイル1つで管理、バックアップが容易

## 実行環境
- **ローカル実行** — Node.jsで直接起動

## MUI 選定理由

本プロジェクトで必要なUIコンポーネントのほとんどをMUI標準またはMUI関連ライブラリでカバーできる：

| 必要な要素 | 対応 |
|---|---|
| テーブル（ソート・展開・ツリー・編集） | TanStack Table + MUIコンポーネントで描画 |
| タブ・ダイアログ | MUI Tabs, Dialog |
| カレンダー・時刻ピッカー | MUI X Date/Time Pickers |
| ツリー表示（文書管理） | MUI X Tree View |
| 円グラフ | MUI X Charts |
| フォーム要素全般 | MUI TextField, Select, Slider, Chip 等 |
| 色選択（タグ・タイプ） | 別途小型ライブラリ or カスタム |
| マークダウンエディタ | 別途ライブラリ（MDXEditor等） |
| タイムライン操作 | 別途ライブラリ or 自作（実装時に調査） |

テーブルはTanStack Tableでロジックを管理し、MUIコンポーネントでセルを描画する。スマホではカード型レイアウトへの切り替えも自由に行える。
MUI標準でカバーできないのはマークダウンエディタとタイムライン操作のみで、これらは個別に対応する。
