# 機能要件詳細

## 共通

- 全画面レスポンシブ対応（PC: テーブル表示、スマホ: カード表示に切り替え）
- ナビゲーション: サイドバー（PC）/ ボトムナビ or ハンバーガー（スマホ）で各画面に遷移
- 期間セレクタ（完了履歴・デイリー統計・資産統計で共通）: 日/週/月の切り替え＋左右矢印で期間移動。週は月曜始まり日曜終わり、月は1日始まり

---

## 1. デイリー

### 1-1. 記録タブ

**日付選択**
- カレンダーで日付を指定。デフォルトは今日

**目標・振り返り**
- 各日付に対して目標（文字列）と振り返り（文字列）を1つずつ記録
- 未入力でも可

**タイムライン**
- 0時〜24時の縦軸目盛り
- 行動ブロックを時間帯上に配置
- 空白時間をクリック → 行動作成ダイアログ
  - タイプ: 大分類を選択 → その中の小分類を選択
  - 詳細: 任意の文字列
  - 開始時刻: タップ位置の時刻、終了時刻: 開始から30分後に自動設定
- 既存行動をクリック → タイプ・詳細を編集
- 行動ブロックの操作（実装時にライブラリ調査、なければ後回し）:
  - 中間ドラッグ → 移動
  - 上端/下端ドラッグ → 伸縮
  - 他の行動端・0時・24時にスナップ
  - 行動同士は重ならない

### 1-2. 統計タブ

- 期間セレクタで期間を指定
- 大分類/小分類の切り替えが可能
- 表示内容:
  - 円グラフ（タイプ別の時間割合）
  - リスト: 各タイプの総時間、割合(%)、一日平均時間

### 1-3. タイプタブ

- 大分類のCRUD。各大分類は名前と色を持つ
- 小分類のCRUD。各小分類は名前を持ち、1つの大分類に属する。色は持たず、グラフ等では大分類の色で表示
- 大分類を削除すると配下の小分類も削除される

## 2. やること

### 2-1. 一覧タブ

**タスクのフィールド**
| フィールド | 型 | 備考 |
|---|---|---|
| 内容 | string | 必須 |
| 詳細 | string | 任意 |
| 重さ | int 0〜5 | 必須、デフォルト1 |
| 期限 | datetime | 任意。時刻のデフォルト23:45、15分単位 |
| 進行状況 | enum | 未着手(赤) / 完了(緑) / 自由記述(黄) |

**前提タスク**
- タスクは他のタスクを前提タスクとして持てる（多重ネスト可）
- 重さ表示: 自身の重さの隣に括弧で前提タスク全体の重さの合計を表示

**テーブル表示**
- 列: 展開矢印、内容、重さ(前提合計)、期限、進行状況、削除ボタン
- 展開すると詳細テキストと前提タスク一覧が表示される
- 各プロパティでソート可能
- 内容・詳細で検索可能
- 進行状況を完了に変更 → 完了日時を自動記録

### 2-2. 繰り返しタスクタブ

**繰り返しタスクのフィールド**
| フィールド | 型 | 備考 |
|---|---|---|
| 内容 | string | 必須 |
| 詳細 | string | 任意 |
| 重さ | int 0〜5 | 必須、デフォルト1 |
| 期限（相対） | duration | タスク追加日からの相対日時 |
| 繰り返し日時 | enum+params | 下記参照 |

**繰り返し種別**
| 種別 | パラメータ |
|---|---|
| 毎日 | 時刻 |
| 毎週 | 曜日（複数選択可）＋ 時刻 |
| 毎月 | 日 ＋ 時刻 |
| 手動 | なし（追加ボタンで手動追加） |

- 自動繰り返し: 指定日時にタスク一覧タブに新規タスクとして追加
- 手動: 追加ボタン押下時にタスク一覧タブに追加
- 進行状況は表示しない

### 2-3. 完了履歴タブ

- 期間セレクタで期間を指定
- 表示: 完了タスクの件数、重さの合計

## 3. 事実＆思考

### 3-1. 一覧タブ

**エントリーのフィールド**
| フィールド | 型 | 備考 |
|---|---|---|
| タイトル | string | 必須 |
| タグ | Tag[] | 0個以上 |
| 内容 | string | 任意 |
| 作成日時 | datetime | 自動記録 |

- 展開すると補足の一覧が表示され、補足の追加・削除が可能
- 補足は文字列のリスト
- タグでフィルタ可能
- タイトル・内容で検索可能
- 各エントリーの右端に削除ボタン

### 3-2. タグタブ

- タグのCRUD。各タグは名前と色を持つ

---

## 4. やらないこと

**エントリーのフィールド**
| フィールド | 型 | 備考 |
|---|---|---|
| 内容 | string | 必須 |
| 削除日時 | datetime | 削除時に自動記録 |

- 上部に週セレクタ（月曜〜日曜）、左右矢印で週移動
- 各エントリーに対して選択中の週の振り返り（文字列）を記録・閲覧できる
- 振り返りは週ごとに別データとして保存される
- 各エントリーの右端に削除ボタン
- 削除は論理削除: 削除日時を記録し、選択中の週が削除日時より前なら表示、削除日時以降なら非表示

---

## 5. 文書管理

- 左サイドバーにフォルダ・文書のツリー
- フォルダは展開・折りたたみ可能
- 操作: 作成、名前変更、削除、移動（ドラッグ or メニュー）、複製
  - 複製後の名前: 「[元の名前]のコピー」
  - フォルダの複製は配下の文書・フォルダも再帰的に複製
  - フォルダの削除は配下も再帰的に削除
- 文書の内容はマークダウンエディタで編集
- フォルダは入れ子可能

**データ格納方式**
- DB内にツリー構造を保存（parent_idによる自己参照）
- 文書の本文もDBにテキストとして格納（ファイルシステムは使わない）

## 6. 資産

### 6-1. 取引タブ

**取引のフィールド**
| フィールド | 型 | 備考 |
|---|---|---|
| 日時 | datetime | 必須 |
| 得たもの | string | 任意（資産名からサジェスト） |
| 得た数量 | number | 得たものがある場合は必須 |
| 失ったもの | string | 任意（資産名からサジェスト） |
| 失った数量 | number | 失ったものがある場合は必須 |

- 得たもの・失ったものの両方が空でもよい（記録のみ）は想定しない。少なくとも片方は必要
- 各取引の右端に削除ボタン

### 6-2. 資産タブ

- 日付を指定し、その日時点の全資産と数量を一覧表示
- 数量 = その日以前の全取引の「得た数量の合計 − 失った数量の合計」

### 6-3. 統計タブ

- 期間セレクタで月/週を指定（日は不要）
- その期間の取引一覧を表示
- 上部に: 日本円の収入合計、支出合計、総損益（収入 − 支出）
  - 収入 = 得たものが「日本円」の取引の数量合計
  - 支出 = 失ったものが「日本円」の取引の数量合計

## 7. ホーム

- **今日中にやること / 今週中にやること**: 切り替え可能。タスク一覧から期限が今日/今週内のものを抽出表示
- **今日の目標**: デイリー画面の今日の目標を表示。未設定なら赤文字で警告
- **今日のタイムライン**: デイリー画面の今日のタイムラインを表示のみで配置。タップでデイリー画面に遷移
- **ランダム情報**: 事実＆思考からランダムに1件表示。画面を開くたびに変わる
